# Movie Genre Prediction

This project predicts the genre of a movie using its plot/description.

## Dataset Used
imdb_top_1000.csv - Contains 1000 movies data from IMDB.

## Technologies Used
- Python
- Pandas
- Scikit-Learn
- Matplotlib

## How it works
1. Data Cleaning
2. Text Vectorization using TF-IDF
3. Model Training
